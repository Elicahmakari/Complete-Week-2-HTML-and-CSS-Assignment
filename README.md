
# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple website
designed to help users record, organize, and monitor their
daily expenses.

The project was developed using HTML and CSS as part of
the Week 1 and Week 2 Web Development assignments.

## Features

1. Expense Entry Form
   - Enter expense name.
   - Enter amount in Kenyan Shillings (KSh).
   - Select an expense category.
   - Select the expense date.

2. Expense Table
   - Displays expense names.
   - Shows amounts spent.
   - Displays expense categories.
   - Shows expense dates.
   - Contains five sample expenses.

3. Multimedia
   - Includes a budget tracker logo.
   - Includes an embedded YouTube budgeting tutorial.

4. Interactive Elements
   - Collapsible instructions using HTML details and summary.
   - Hover effects on table rows.
   - Focus effects on form inputs.

5. CSS Styling
   - Descendant selectors.
   - Direct child selectors.
   - Pseudo-class selectors.
   - Negation selectors.
   - Responsive design for smaller screens.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## Project Files

- index.html: Contains the website structure and content.
- style.css: Controls colors, layouts, tables, forms and styling.
- README.md: Explains the project and its features.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the expense form and table.
